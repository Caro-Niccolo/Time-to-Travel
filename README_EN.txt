TIME TO TRAVEL — GITHUB PAGES DEPLOYMENT

All website files are arranged correctly: index.html is in the repository root. No CNAME file is included.

HOW TO PUBLISH
1. Open the repository: https://github.com/Caro-Niccolo/Time-To-Travel
2. Make sure the main branch is selected.
3. Click Add file → Upload files.
4. Extract this ZIP archive on your computer.
5. Upload ALL files and folders from the extracted folder to the repository root. Upload index.html, all other HTML pages, CSS/JS/JSON files and the assets folder. Do not upload the ZIP as a single file or create an extra nested folder.
6. Click Commit changes.
7. Under Settings → Pages, check: Deploy from a branch; Branch: main; Folder: / (root).
8. After deployment, open: https://caro-niccolo.github.io/Time-to-Travel/

ENQUIRIES
The enquiry form and tour buttons create an email using mailto:travelway@tuta.io. This opens the visitor’s email application; it does not send messages automatically from the website. An external form service is required for automatic submissions.

OFFERS
The catalogue contains six tour records from the source file. Other destinations are listed without invented prices or dates. Please confirm hotel details, prices and availability before accepting bookings.
