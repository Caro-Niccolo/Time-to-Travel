TIME TO TRAVEL — оновлена багатосторінкова версія

Що всередині:
- index.html — головна сторінка
- countries.html — каталог 12 країн
- country.html?name=Turkey — сторінка окремого напрямку (параметр змінюється для кожної країни)
- hot-tours.html — гарячі пропозиції
- early-booking.html — раннє бронювання
- about.html — про нас і дані технологічного партнера
- contacts.html — контакти та форма запиту
- assets/logo.png — витягнутий логотип із наданого оригінального HTML
- data.js — збережені тури, дати та ціни з наданого файлу
- countries.js, app.js, style.css — дані та логіка сайту

Публікація на GitHub Pages:
1. Розпакуйте ZIP.
2. Завантажте ВСІ файли та папки з цієї збірки в корінь репозиторію Time-To-Travel (гілка main).
3. Замініть старий index.html новим index.html.
4. Не додавайте CNAME автоматично: ця збірка не потребує його для адреси github.io.
5. У Settings → Pages залиште Deploy from a branch → main → /(root).

Важливо:
- Не додавалися вигадані дати чи ціни для нових країн. Для напрямків без турів є кнопка/сторінка запиту.
- У шести турах збережено дати, ціни та готелі з наданого файлу; актуальність треба підтвердити перед продажем.
- Форма готує лист через поштову програму на travelway@tuta.io, як у наданому вихідному файлі. Автоматична доставка без поштової програми потребує окремого сервісу форм.
