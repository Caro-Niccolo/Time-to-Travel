TIME TO TRAVEL — ПУБЛІКАЦІЯ НА GITHUB PAGES

У цьому архіві файли вже розкладені правильно: index.html знаходиться в корені,
а не у вкладеній папці. CNAME не додавався.

ЯК ОПУБЛІКУВАТИ:
1. Відкрийте репозиторій:
   https://github.com/Caro-Niccolo/Time-To-Travel
2. Переконайтеся, що відкрито гілку main.
3. Натисніть Add file → Upload files.
4. Відкрийте ZIP на комп'ютері та розпакуйте його.
5. Завантажте ВСІ файли та папки з цієї папки до кореня репозиторію.
   Важливо: завантажуйте index.html, style.css, app.js, data.js,
   countries.js, countries.json, усі HTML-сторінки та папку assets.
   Не завантажуйте саму ZIP-папку як один файл і не створюйте ще одну
   вкладену папку time-to-travel-redesign.
6. Унизу сторінки натисніть Commit changes.
7. У Settings → Pages перевірте:
   Build and deployment: Deploy from a branch
   Branch: main
   Folder: / (root)
8. Зачекайте завершення публікації та відкрийте:
   https://caro-niccolo.github.io/Time-to-Travel/

ВАЖЛИВО ПРО ЗАЯВКИ:
Форма та кнопки запиту готують лист через mailto:travelway@tuta.io.
Це відкриває поштову програму користувача, але не надсилає заявку
автоматично з сайту. Для автоматичного отримання заявок потрібне
підключення окремого сервісу форм.

ВАЖЛИВО ПРО ПРОПОЗИЦІЇ:
У каталозі залишені шість записів турів із вихідного файлу.
Інші країни є в каталозі напрямків, але не мають вигаданих цін чи дат.
Перед прийманням бронювань перевірте актуальність готелів, цін і дат.
